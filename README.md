# Axis — Painel Pessoal & Carreira (PWA)

Pacote pronto para publicação no **GitHub Pages** e empacotamento como **APK Android** pelo **PWABuilder**.

## Conteúdo já incluído neste ZIP
- `index.html`, `manifest.json`, `sw.js`
- `css/styles.css`
- `js/icons.js`, `js/storage.js`, `js/app.js`
- `icons/icon-192.png`, `icons/icon-512.png`, `icons/icon-512-maskable.png` (prontos para Android)
- `icons/icon-192.svg`, `icons/icon-512.svg`

## Publicação Rápida (3 passos)
1. Extraia este ZIP.
2. Crie um repositório **público** no GitHub (ex: `axis-painel`) e arraste **todos os arquivos e subpastas de dentro de `axis-pwa/`** para a raiz do repositório.
3. Ative **Settings → Pages → Branch: `main` / `/ (root)`** e use o link gerado no [pwabuilder.com](https://www.pwabuilder.com) para baixar seu `.apk`.
